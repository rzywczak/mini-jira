# Mega Jira

Mega Jira is a lightweight project management application inspired by Jira. It provides a simple Kanban board for creating tasks, tracking their progress, and moving them between **To Do**, **In Progress**, and **Done**.

## Features

- Create tasks with a title, description, and status
- View tasks in a clear three-column board
- Update task statuses as work progresses
- Track the total number of tasks

Built with React, TypeScript, Redux Toolkit, Sass, and Vite.
